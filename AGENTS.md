# Project Development Guidelines

## Git Guidelines

- Do not rewrite published Git history.
- Do not force push to shared branches.
- Keep existing commits intact.
- Use normal commits and pushes for project updates.
- Keep the main branch in a working state.

## Development Guidelines

- Test changes locally before deployment.
- Run `npm run build` before production deployment.
- Preserve existing functionality unless intentionally changed.
- Keep the project structure clean and maintainable.
- Use clear and descriptive commit messages.
